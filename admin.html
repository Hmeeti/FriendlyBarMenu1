Где взять ключ?
  1. Откройте новый токен на GitHub (войдите в аккаунт с доступом к репозиторию).
  2. Repository access → Only select repositories → репозиторий меню.
  3. Permissions → Repository: Contents — Read and write, Actions — Read-only.
  4. Нажмите Generate token и вставьте его сюда.
